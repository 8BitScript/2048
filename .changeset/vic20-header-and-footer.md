The VIC-20 is a header and one footer row. The board takes 4×4 tiles (rounded, like the C64's, with empty squares in blue so they no longer look like a "2"), sits one column right so its margins read even, and fills rows 2–20. The footer holds the copyright until the first move, then a short move hint (USE ARROWS) and the version, both inside the board's edges. SCORE and the number have a space between them on every fixed grid and the narrow web layout. Measured: VIC-20 8K 3874 bytes of program from 3639; C64 5470, CX16 4357.
