On the PET the empty tile is the numbered tile's size. Its checkerboard had been cut to 15×9 quadrants so all four corners rounded alike, which left it half a cell smaller each way than a tile with a number on it. It is back to the full 8×5 cells, with the two lit corners notched. Measured on the PET 4032: 6343 bytes of program from 6458.
